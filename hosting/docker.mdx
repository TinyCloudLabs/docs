For an ordinary VPS, follow the [personal-node guide](https://github.com/TinyCloudLabs/tinycloud-node/blob/main/deploy/personal-node/README.md). Its Compose profile pins the published 1.22.0 ordinary-node image by digest, mounts a keyless configuration, persists SQLite and local blocks, terminates HTTPS at Caddy, and uses an installation-specific persistent key. The guide's CI rehearsal uses the same operator script to check signed KV/SQL, restart, fresh-volume restore, upgrade from 1.20.6 to 1.22.0, restore-based rollback, and that the bare published 1.22.0 image fails closed without a key. The upgrade applies database migrations, so rollback restores the pre-upgrade backup. Named keys and delegated SQL caveats are disabled by default in 1.22.0 and are not enabled by the guide.

Do not use a mutable image tag or the dstack Compose profile as an ordinary-server recipe; pin the image by digest as the guide does. The guide names what its published-image job has verified. Running an ordinary VPS does not provide TEE attestation or dstack key isolation.

For configuration details, see [Configuration](/hosting/configuration). Keep the node's plain HTTP API and unauthenticated metrics private; expose only the HTTPS reverse proxy. Retain the node root and an offline data backup independently.
