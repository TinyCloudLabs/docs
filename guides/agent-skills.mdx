Coding agents use TinyCloud through the `tc` CLI. The CLI's npm package ships
a `tc-cli` skill that teaches an agent the commands, the auth flows, and the
error codes for that exact release. Install the CLI, then install its skill
into each agent client you use.

## Install the CLI and the `tc-cli` skill

The skill installer needs Node.js 22.20 or newer; the CLI alone needs 20.

```bash
npm install --global @tinycloud/cli@1.0.0
TC="$(npm prefix --global)/bin/tc"      # avoids /usr/sbin/tc on Linux
VERSION="$("$TC" --version)"
npx --yes skills@1.7.0 add \
  "https://registry.npmjs.org/@tinycloud/cli/-/cli-${VERSION}.tgz" \
  --skill tc-cli --global --copy --agent opencode codex claude-code --yes
```

This copies the skill for that CLI release into each client's skill directory:
`~/.claude/skills` for Claude Code, and `~/.agents/skills` for OpenCode and
Codex. Pass only the agents you use. Start a new agent session and ask it to
use `tc-cli`.

<Warning>
On Linux, `tc` on the `PATH` often resolves to `/usr/sbin/tc`, the iproute2
traffic-control tool. Point agents at the CLI by absolute path, as above.
</Warning>

## Check, update, and remove

```bash
"$TC" --version
npx --yes skills@1.7.0 list --global
```

The installed `tc-cli/release.json` names the CLI range the skill describes
(`>=1.0.0-beta.17 <2.0.0` for 1.0.0). To update, install the new CLI version
and rerun `skills add` with that version's tarball URL; a pinned URL never
updates itself.

```bash
npx --yes skills@1.7.0 remove tc-cli --global --agent opencode codex claude-code --yes
npm uninstall --global @tinycloud/cli
```

Removing the skill or the CLI does not delete TinyCloud profiles or revoke any
access an agent was granted. Revoke those with `tc delegation revoke` or from
the account app.

## Give the agent its own access

An agent should sign in on its own profile with only the access its task needs,
approved by the owner through OpenKey:

| Task | How the agent gets access |
|---|---|
| Publish Share links | `tc --profile publisher enable share` (device approval); see [Share files](/cli/share) |
| Read named API keys | Scoped paste login with a `secrets` manifest; see [Secrets](/cli/secrets#give-an-agent-read-access-to-a-secret) |
| Explore and edit app data | MCP with a delegate profile; see [Access and explore my TinyCloud](/guides/access-and-explore-my-tinycloud) |

## App skill packs

App skill packs build on `tc-cli` for one job and publish their own CLI
requirements. The packs below are in
[TinyCloudLabs/prompts](https://github.com/TinyCloudLabs/prompts), currently in
preview:

- **`tc-publish`** publishes a document or HTML page and returns an owner-only
  or public Share link.
- **`tc-secrets`** reads API keys the owner keeps in Secret Manager, without
  the values passing through chat.

Install a pack by copying its directory into the agent's skill path, and follow
its `QUICKSTART.md` for the operator settings it expects. Packs never install
software themselves; if the CLI is too old they stop and say so.
